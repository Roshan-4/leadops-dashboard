# LeadOps dashboard

Static dashboard for **LeadOps** (Tractor Junction lead automation).
Live: https://roshan-4.github.io/leadops-dashboard/

It works only together with the **LeadOps Agent** running on the same Windows PC, with an
Android phone connected by USB. Sign in with your Tractor Junction app account.
This repository contains the page only — no data, no credentials.
